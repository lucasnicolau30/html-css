HTML and CSS exercises and mini-projects from an introductory web development course, covering everything from basic markup to responsiveness.

## Structure

```
html-css/
├── 1° Parte                              (Intro to HTML - tags, forms, tables)
├── 2° Parte                              (Intro to CSS - selectors, colors, fonts, borders)
├── 3° Parte                              (Box model, floats, positioning, inline/block elements)
├── 4° Parte - CSS3(Intermediário_Avançado) (CSS3 intermediate/advanced - rounding, layouts, forms, inheritance)
├── 5° Parte - Recursos_Especiais          (Special features - flexbox, animations, transitions, gradients, shadows)
└── 6°  Parte - Resposividade + Projeto     (Responsiveness + final project - Instagram clone layout)
```

Each folder holds `.html` and `.css` files for one stage of the course, grouped by topic.

## How to run

Open any `.html` file directly in your browser:

```bash
cd "1° Parte"
start Projeto1.html
```
