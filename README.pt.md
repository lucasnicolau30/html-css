Exercícios e mini-projetos de HTML e CSS de um curso introdutório de desenvolvimento web, cobrindo desde marcação básica até responsividade.

## Estrutura

```
html-css/
├── 1° Parte                              (Introdução ao HTML - tags, formulários, tabelas)
├── 2° Parte                              (Introdução ao CSS - seletores, cores, fontes, bordas)
├── 3° Parte                              (Modelo de caixa, elementos flutuantes, posicionamento, inline/block)
├── 4° Parte - CSS3(Intermediário_Avançado) (CSS3 intermediário/avançado - arredondamento, layouts, formulários, herança)
├── 5° Parte - Recursos_Especiais          (Recursos especiais - flexbox, animações, transições, degradês, sombras)
└── 6°  Parte - Resposividade + Projeto     (Responsividade + projeto final - layout estilo Instagram)
```

Cada pasta contém os arquivos `.html` e `.css` de uma etapa do curso, agrupados por tópico.

## Como executar

Abra qualquer arquivo `.html` diretamente no navegador:

```bash
cd "1° Parte"
start Projeto1.html
```
